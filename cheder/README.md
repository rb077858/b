# תורנויות חדר (cheder)

אתר לסידור הניקיון היומי בחדרים בפנימייה. כתובת: `https://reembir.com/b/cheder/` · ניהול: `https://reembir.com/b/cheder/admin/`

## איך זה עובד
- **כניסה עם Google.** רק מי שהמנהל (rb077858@gmail.com) צירף לחדר נכנס, ורואה רק את החדר שלו. גם המנהל לא נכנס לאתר הרגיל עד שהוא מצרף את עצמו.
- **החדר מוסיף את הדיירים** (שמות בלבד - לא צריך חשבון לכל אחד).
- **כל בוקר חלוקה חדשה:** כל אחד מסדר מיטה, פינוי שולחן וטאטוא מתחלקים, ובחמישי גם שטיפה.
  כשהחדר בתורנות קומה: טאטוא מסדרון, שירותים, כיורים, אסלות. בתורנות מטבחון: מטבחון, מועדון, מחוץ לפנימייה.
- **החלוקה הוגנת:** קודם מאזנת את היום לפי "משקל" המשימות, ואז נותנת יותר למי שעשה פחות ב-30 הימים האחרונים (יחסית לימים שהיה בחדר), ומשתדלת לא לחזור על אותה משימה ברצף.
- **הדבקת ההודעה של המדריך:** בלשונית "תורנות" מדביקים את ההודעה מהקבוצה (גם כמה הודעות יחד). המערכת מזהה את התאריך, חדרי הקומה וחדר המטבחון, ואפשר לתקן לפני השמירה. חדר אחד שמדביק - מעדכן את כולם.
- **חולה / לא הגיע / בבית:** ⋯ ליד השם, לכמה זמן שרוצים. המשימות עוברות לאחרים, ומה שכבר בוצע נשאר.
- **החלפות:** ⇄ ליד משימה מעביר אותה; ⋯ ← "החלפת תורנות" מחליף בין שניים את כל המשימות של היום. החלפה בין חדרים: "עריכה / החלפה" בלשונית תורנות.
- **לו"ז לשבוע הקרוב** + שינויים: חופשה/טיול (אין משימות), העברת יום השטיפה, יום שטיפה נוסף, ביטול שטיפה, בלי תורנות, יום רגיל בשבת, הערה. לכל הפנימייה או רק לחדר.

## קבצים
| קובץ | תפקיד |
|---|---|
| `index.html`, `app.js` | האתר לחדרים |
| `admin/` | ממשק הניהול: צירוף אנשים לחדרים, לו"ז קבוע |
| `core.js` | כל הלוגיקה (פענוח הודעות, ימים, חלוקה הוגנת) |

| `test/core.test.mjs` | בדיקות ללוגיקה: `node cheder/test/core.test.mjs` |

## מבנה הנתונים (Firestore, אוספים `ch_*`)
- `ch_members/{מייל}` - מי מורשה ובאיזה חדר. רק אדמין כותב.
- `ch_rooms/{חדר}` - דיירים, היעדרויות, שינויים של החדר. `ch_rooms/{חדר}/days/{YYYY-MM-DD}` - החלוקה של כל יום ומה בוצע. רק החדר עצמו והאדמין.
- `ch_duties/{YYYY-MM-DD}` - תורנות קומה/מטבחון מהודעת המדריך. כל חדר מורשה כותב, רק אדמין מוחק.
- `ch_events/{id}` - שינויים בלו"ז לכל הפנימייה. מי שהוסיף (או אדמין) מוחק.
- `sites/cheder` - הגדרות (ימים פעילים, יום שטיפה). קריאה ציבורית, כתיבה לאדמין.

## הפעלה
1. **פריסת החוקים** (מתיקיית המאגר): `npx firebase-tools deploy --only firestore:rules`
2. כניסה ל-`/cheder/admin/`, צירוף אנשים לחדרים (וגם את עצמך).


## בדיקות
- לוגיקה: `node cheder/test/core.test.mjs`
- חוקי Firestore (אמולטור, דורש Java): `cd firebase/rules-test && npm install --legacy-peer-deps && npm test`
- בדיקה מקומית של האתר מול אמולטורים: פותחים `http://localhost:<port>/cheder/?emu` (לא פעיל באתר האמיתי).
