# דף · עורך דף גמרא

אתר לעריכת דף גמרא בצורת דף וילנא הקלאסי: הגמרא באמצע, רש"י ותוספות סביבה, והשוליים מצדדים (עין משפט, מסורת הש"ס, רבינו חננאל, גליון הש"ס ועוד).
הדפים שבאים מוכנים הם **בבא מציעא לג: ולד.**

## איך משתמשים
- **לחיצה על כל מילה** בדף פותחת חלונית עריכה קטנה (נוחה גם בטלפון): מקלידים והדף מתעדכן מיד. אפשר לעבור למילה הבאה/הקודמת, למחוק ולהדגיש.
- **"עריכת כל הקטע"** פותח את כל הטקסט של החלק (גמרא / רש"י / תוספות / קטע בשוליים) בתיבה גדולה.
- **לחיצה על הכותרת** (שם הפרק, המסכת או מספר הדף) פותחת את פרטי הדף, כולל עמוד א/ב (קובע אם רש"י מימין או משמאל).
- **עיצוב**: גודל אותיות, רוחב הגמרא, כמה שורות פתיחה יש מעל הגמרא, צבע נייר, ופונטים. אפשר להעלות פונט משלכם (TTF/OTF/WOFF), למשל את הפונטים המקוריים של הש"ס אם יש לכם אותם.
- **הורדת תמונה**: PNG באיכות גבוהה של העמוד הנוכחי. בתפריט ⋮ אפשר להוריד את כל העמודים יחד, לשתף, להדפיס או לשמור PDF, ולשמור או לפתוח קובץ עבודה.
- הכול נשמר אוטומטית בדפדפן. ↶ / ↷ מבטלים ומחזירים שינויים.

## סימונים בטקסט
| סימון | תוצאה |
|---|---|
| `**מילים**` | מודגש (דיבור המתחיל) |
| `{{מילה}}` | מילה גדולה (פתיחה) |
| `^א^` | אות קטנה (ציון למסורת הש"ס / עין משפט) |
| שורה שמתחילה ב-`# ` | כותרת ממורכזת (למשל "הדרן עלך") |
| ירידת שורה | פסקה חדשה |

## קבצים
- `index.html`, `style.css`, `app.js`: האתר עצמו (סטטי, בלי בנייה ובלי תלויות).
- `data.js`: הטקסט של הדפים המקוריים.
- `fonts/`: Frank Ruhl Libre, Noto Rashi Hebrew ו-David Libre (רישיון SIL Open Font License).
- `lib/html-to-image.js`: ספרייה ליצירת התמונה (רישיון MIT).

כדי שהורדת התמונה תעבוד צריך לפתוח את האתר דרך שרת (למשל GitHub Pages, או `python3 -m http.server` בתיקייה), ולא ישירות מהקובץ.

## איך עובד הסידור
הדף בנוי משלוש שכבות שיושבות אחת על השנייה: גמרא, רש"י ותוספות. בכל שכבה יש "מרווחים" צפים (floats) שמשאירים מקום לשכבות האחרות. אחרי כל שינוי, `layoutPage` מחשב מחדש את גובה המרווחים, כך שהטקסט שומר על צורת הדף:
שורות פתיחה מעל הגמרא, עמודות צרות לצידה, והתרחבות מתחתיה. כשאחד הפירושים נגמר, הגמרא או הפירוש השני מתרחבים למקום שהתפנה. השוליים מתכווצים אוטומטית כדי להסתיים יחד עם הדף.
