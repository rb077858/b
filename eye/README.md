# בדיקת חדות ראייה

אתר בדיקת ראייה להדגמה בקובץ אחד (`index.html`), בלי תלויות, שרץ בטלפון ובמחשב.

- כיול גודל המסך לפי מטבע 10 אגורות, ₪1, ₪5, ₪10 או כרטיס אשראי (קנה מידה 1:1)
- בדיקה לפי מרחק (2/3/4 מטר) עם אותיות, ספרות או E, מסך מנחה ומקלדת
- כל עין בנפרד, שתי עיניים ובדיקה חוזרת דרך חור סיכה
- שאלון אופציונלי: כל שאלה אפשר לדלג עליה או לסמן "לא ידוע"
- סיכום על צורך אפשרי במשקפיים, ותמונת דוח לשמירה ושיתוף

הבדיקה להדגמה בלבד ואינה מחליפה בדיקה אצל אופטומטריסט.

הרצה: לפתוח את `index.html` בדפדפן.

## טלפון כמקלדת

המנחה לוחץ על "חבר טלפון כמקלדת" (במסך ההנחיות או במסך הבדיקה). מופיעים ברקוד וקוד של 6 ספרות. הטלפון השני סורק את הברקוד, או פותח את האתר ולוחץ "אני הטלפון-מקלדת" ומזין את הקוד. הטלפון מציג מקלדת לפי מה שנבחר (אותיות, ספרות או חיצים), ולחיצות עוברות ישר למכשיר המנחה. עובד גם בין מחשב לטלפון.

- החיבור ישיר בין המכשירים (WebRTC). שירות ההתאמה הציבורי של PeerJS משמש רק ברגע ההתחברות, בלי הרשמה ובלי שמירת מידע.
- כתובת הברקוד מצביעה על GitHub Pages: https://reembir.com/b/eye/
- ברשתות מסוימות (חוסמות חיבור ישיר) החיבור עלול להיכשל. אז כדאי לחבר את שני המכשירים לאותה רשת Wi-Fi.
