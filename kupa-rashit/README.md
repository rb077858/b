## הנגן
- **השהיה אוטומטית**: כל מכשיר מגדיל את ההשהיה כשהשידור נתקע אצלו, ומקטין בהדרגה כשהחיבור יציב. ההשהיה נשמרת במכשיר.
- **חזרה אחורה (DVR)** דרך הפרמטר `dvr` של שרת השידור: "מתחילת התוכנית", גלילה בציר הזמן עם שעון אמיתי, צפייה חוזרת אחרי השידור.
- **צפייה משותפת (🔗)**: כפתור הקישור בנגן מעתיק קישור (`#s=<חדר>`). כל מי שנכנס אליו רואה בדיוק את אותו רגע כמו השולח (בדיוק של מאיות שנייה), עד שאחד הצדדים משנה ידנית (ניגון/השהיה, דילוג, גלילה, "לשידור החי", מהירות, השהיה), ואז הסנכרון מתבטל אצלו בלבד.
  - **שעון משותף** (`sync.js`): כל מכשיר מודד את ההפרש מהשעון של Cloudflare (`/cdn-cgi/trace`), עם בקשות שמכוונות בדיוק ל"תקתוק" השנייה. דיוק: ±9 אלפיות לכל היותר, בפועל כאלפית אחת.
  - **חדר במסד הנתונים**: `kr_sync/<חדר>` שומר את ה"פיגור" מהזמן האמיתי. `peers/` = מי צופה כרגע והסטייה שלו (מוצג בתג "צפייה משותפת · 3 צופים · סטייה 0.01 שנ׳").
  - **בקרה בנגן**: 4 פעמים בשנייה בודקים איזו תמונה מוצגת ממש עכשיו (`requestVideoFrameCallback`) ומתקנים בשינוי מהירות זעיר. סטייה מעל 1.5 שניות = קפיצה.
  - אם המסד לא זמין, מוצע קישור חלופי `#w=...` שנושא את הפיגור בעצמו.
- איכות, מהירות, תמונה-בתוך-תמונה, מסך מלא, מקשי קיצור, הקשה כפולה לדילוג בטלפון, נתונים טכניים, מסך לא נכבה בזמן צפייה.

## קבצים
- `index.html`: הדף הציבורי. קורא את ההגדרות מ-Firestore (`sites/kupa-rashit`) בזמן אמת.
- `player.js`: הנגן (hls.js, ובאייפון נגן מובנה).
- `schedule.js`: לוגיקת הלוח וברירות המחדל (גיבוי אם אין חיבור למסד הנתונים).
