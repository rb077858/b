# kupa-rashit (reembir.com/b/kupa-rashit)

דף שמעביר אוטומטית לשידור החי כשמגיעה שעת השידור (לפי שעון ישראל).

## איך עורכים
פותחים את `index.html` ועורכים רק את בלוק ההגדרות בראש הקובץ (בין `⚙️ הגדרות` ל-`סוף ההגדרות`):

| מה רוצים | איפה |
|---|---|
| להוסיף / לשנות / למחוק שעה קבועה שבועית | `WEEKLY_SCHEDULE` |
| תאריך מיוחד עם שעה, שם וקישור משלו | `SPECIAL_BROADCASTS` |
| לבטל שידור קבוע בתאריך מסוים | `CANCELLED_DATES` |
| שם וקישור ברירת מחדל | `DEFAULT_SHOW_NAME`, `DEFAULT_LIVE_URL` |

בכל שורה אפשר להוסיף `name` (שם) ו-`url` (קישור) כדי שיחולו רק על אותה שורה.
בכל תאריך מיוחד אפשר להוסיף גם `label` (הערה שמוצגת למשתמש).

ימים: 0=ראשון, 1=שני, 2=שלישי, 3=רביעי, 4=חמישי, 5=שישי, 6=שבת.
