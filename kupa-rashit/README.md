# kupa-rashit (reembir.com/b/kupa-rashit)

דף שמעביר אוטומטית לשידור החי כשמגיעה שעת השידור (לפי שעון ישראל).

## איך עורכים
**לא עורכים קבצים.** הכל מנוהל מפאנל הניהול:
👉 https://reembir.com/b/admin/ (כניסה עם Google, rb077858@gmail.com)

בפאנל:
- **סקירה**: סטטוס חי, ספירה לאחור, לוח 14 ימים, מעבר מיידי ל"שידור עכשיו" / "מושבת"
- **שידורים קבועים**: שעות שבועיות (כולל שידור שחוצה חצות)
- **תאריכים מיוחדים**: שידורים חד-פעמיים עם שם, קישור והערה משלהם
- **ביטולים**: תאריכים שבהם השידור הקבוע לא פועל
- **טקסטים**: כל טקסט שמוצג לצופים
- **עיצוב**: ערכות צבעים, צבעים חופשיים, גופן, רקע, לוגו, אנימציה, CSS, עם תצוגה מקדימה חיה
- **הגדרות מתקדמות**: השהיות, העברה מוקדמת, שעון שרת, העברה אוטומטית
- **גיבוי והיסטוריה**: כל שמירה נשמרת, שחזור בלחיצה, ייצוא/ייבוא JSON

## קבצים
- `index.html`: הדף הציבורי. קורא את ההגדרות מ-Firestore (`sites/kupa-rashit`) ומתעדכן בזמן אמת.
- `schedule.js`: לוגיקת הלוח וברירות המחדל (משמשות כגיבוי אם אין חיבור למסד הנתונים).
