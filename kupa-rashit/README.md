# kupa-rashit (reembir.com/b/kupa-rashit)

דף השידור של "קופה ראשית". בשעת השידור מופעל **נגן מוטמע** (HLS) בתוך הדף, בלי העברה לאתר אחר.

| לשונית | מה יש בה |
|---|---|
| ראשי | סטטוס חי, מצב הדף (אוטומטי / משדרים עכשיו / מושבת), השידורים הקרובים |
| מתי משדרים | לוח 14 ימים, שעות שבועיות, שידורים חד-פעמיים, שבועות בלי שידור |
| נגן | מקור השידור (m3u8) + בדיקה, השהיה (אוטומטית לכל מכשיר / קבועה), כניסה באמצע, שמירת מיקום, סוף תוכנית, צפייה חוזרת |
| עיצוב | ערכות צבעים + תצוגה מקדימה חיה |
| עוד | טקסטים, תזמון מתקדם, גיבויים והיסטוריה |

## הנגן
- **השהיה אוטומטית**: כל מכשיר מגדיל את ההשהיה כשהשידור נתקע אצלו, ומקטין בהדרגה כשהחיבור יציב. ההשהיה נשמרת במכשיר.
- **חזרה אחורה (DVR)** דרך הפרמטר `dvr` של שרת השידור: "מתחילת התוכנית", גלילה בציר הזמן עם שעון אמיתי, צפייה חוזרת אחרי השידור.
- **שמירת מיקום**: חזרה לדף באותה תוכנית ממשיכה מאיפה שעצרו.
- איכות, מהירות, תמונה-בתוך-תמונה, מסך מלא, מקשי קיצור, הקשה כפולה לדילוג בטלפון, נתונים טכניים, מסך לא נכבה בזמן צפייה.

## קבצים
- `index.html`: הדף הציבורי. קורא את ההגדרות מ-Firestore (`sites/kupa-rashit`) בזמן אמת.
- `player.js`: הנגן (hls.js, ובאייפון נגן מובנה).
- `schedule.js`: לוגיקת הלוח וברירות המחדל (גיבוי אם אין חיבור למסד הנתונים).
