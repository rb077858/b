# memes (reembir.com/b/memes)

מחולל ממים לעיתון השנתי של בני עקיבא.

- **דף יצירה** `memes/`: בוחרים קטגוריה, אחר כך תמונה, כותבים עד שני טקסטים (עליון ותחתון, בפונט Impact) ושולחים לבדיקה. המשתמשים לא יכולים להוריד את המם.
- **גרירת טקסט**: בעורך אפשר לגרור כל טקסט למקום אחר בתמונה (עכבר או אצבע), עם הצמדה למרכז. כפתור ↺ ליד כל תיבת טקסט מחזיר אותו למקום המקורי. גם בעריכה בניהול.
- **ניהול** `memes/admin/`: כניסה עם Google (רק rb077858@gmail.com). צפייה בכל הממים בזמן אמת, סינון חדשים/הורדו, עריכה, מחיקה והורדה כ-JPG. מם שהורד מסומן "הורד".
  - **קיצורי מקשים** (במחשב): `?` פותח את הרשימה. חצים למעבר בין ממים, `1/2/3` לסינון, `S` בחירה, `D` הורדה, `E` עריכה, `M` סימון, `Delete` מחיקה, `Esc` יציאה. עובד גם כשהמקלדת בעברית.
  - **בחירה מרובה**: כפתור "בחירה" למעלה (או לחיצה ארוכה על מם). אפשר לבחור כמה ממים או "בחירת הכל" ולבצע עליהם הורדה (כמה ממים יורדים כקובץ ZIP אחד), סימון כהורד/כחדש, או מחיקה.

## נתונים
אוסף `memes` ב-Firestore. **התמונה עצמה לא נשמרת**, רק הקישור למקור והטקסטים:
`imageUrl, thumbUrl, sourceId, category, sourceDesc, top, bottom, size, topPos?, bottomPos?, status ('new'|'downloaded'), createdAt`.
כל אחד יכול רק ליצור מם (בפורמט שנבדק בחוקים, ותמונה רק מ-memeking). קריאה, עריכה ומחיקה: אדמין בלבד.

`topPos`/`bottomPos` = מרכז הטקסט כשבר מגודל התמונה `{x, y}` (0..1). אם אין - הטקסט במקום ברירת המחדל.

## הערות
- הממים נטענים מ-`https://memeking.co.il/api/memes/category/<id>` (בלי www: לתעודת האבטחה של www פג תוקף).
- לתמונות של memeking אין CORS, ולכן ההורדה בניהול טוענת אותן דרך `wsrv.nl`.
- פונט: Impact. בטלפונים (שאין בהם Impact) Anton, ולעברית Heebo Black.
- `meme.js` משותף לשני הדפים (ציור המם), כך שהמם בניהול נראה בדיוק כמו אצל היוצר.
