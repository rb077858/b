# מלאי בגדים

אתר קטן וצבעוני לספירת הבגדים בארון.

## מה יש בו
- כרטיס לכל סוג בגד, עם איור מצויר: ג'ינסים, חולצות, מכנסי פיג'מה, חולצות פיג'מה, ציציות, גרביים ותחתונים דולקים מההתחלה. כובעים, חולצות מכופתרות, מכנסי בד, חליפות, גופיות, סוודרים, מעילים, כיפות, נעליים ומגבות כבויים ואפשר להדליק אותם במתג.
- **הוספת סוג בגד** משלכם, עם שם, איור וצבע לבחירה. אפשר למחוק סוגים שהוספתם.
- כמות לכל סוג, ו"כל פריט מספיק ל־" (ימים, שבועות, חודשים או שנים, לא חובה). האתר מחשב לכמה זמן יספיק כל המלאי.
- הערה לכל סוג והערות כלליות.
- **"סיימתי! צור תמונה"** יוצר תמונת PNG בתבנית קבועה וצבעונית: שם, תאריך עברי ולועזי, סיכום, כרטיס לכל בגד והערות. אפשר להוריד אותה או לשתף.
- הכול נשמר אוטומטית בדפדפן.

## קבצים
- `index.html`, `style.css`: המבנה והעיצוב.
- `icons.js`: האיורים (SVG).
- `app.js`: הלוגיקה ותבנית התמונה (canvas).
